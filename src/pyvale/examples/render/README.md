# Rendering examples

These examples use `pyvale.render`. Riley is the default 3D renderer; the
planar `ImageDef2D` workflow is provided separately for orthographic image
warping. PixInt2D provides analytic Grid2D and Speck2D images through its
Riley-ordered Newton element mappings.

Blender examples use the same public scene data as Riley. Install the Blender
extra on Python 3.13 before running ``ex6_*`` examples.
