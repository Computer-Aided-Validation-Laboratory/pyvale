Validation examples
===================

Each example is an independent tutorial with explicit data preparation, analysis,
post-processing and visualisation. Outputs are saved beneath its own directory
in `pyvale-output`; interactive plotting and console inspection are opt-in.

0. Quickstart: transient temperature and strain, repeats, epistemic scenarios,
   calibration offsets, metric histories, CDFs and a PyVista simulation overlay.
1. Data model: geometry, observable definitions, domain, named array axes,
   source data and tag matching in a validation case.
2. Steady plate: multiple points, components and observable tags.
3. Sampled epistemic uncertainty: conditional distributions and scenario selection.
4. Calibration offsets: coherent asymmetric measurement bounds in a steady case.
5. Transient validation: physical time and repeated observations.
6. Diagnostics: CDF families, envelope choices, directional distances and model
   support corrections.
7. Data conversion: SensorSim acquisitions and sampled simulation fields.
8. Three-dimensional tensor fields and metric overlays.
9. MOOSE cube parameter sweep with 10% perturbations.
10. Pulse25X paper reproduction, including frozen numerical parity checks:
    Horne-Jones et al. (2026), https://arxiv.org/abs/2605.11886.
