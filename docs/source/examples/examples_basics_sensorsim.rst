Basic Sensor Simulation
=======================

Build virtual sensor arrays and sample finite-element fields. Start with a
quick simulation, explore scalar/vector/tensor measurements, then repeat virtual
experiments. Continue with :doc:`examples_ext_sensorsim` for custom data and
more detailed error models.
